In this directory, we provide interactive HTML visualizations of **4000 randomly sampled code translation rules** generated by RulER. The visualizations aims to help readers review and understand these rules more conveniently and intuitively.

## Steps to Review the Translation Rules

1. Navigate to the subdirectory corresponding to the translation rules you want to view. (*each subdirectory named `Visualization-of-Rule-from-[SourceLang]-to-[TargetLang]` contains 1000 HTML files, where each file visualizes a translation rule from *source-language* to *target-language*.*)
    - [Visualization-of-Rule-from-Java-to-Cpp/](https://imjinshuo.github.io/RulER/visualization-of-mined-rules/Visualization-of-Rule-from-Java-to-Cpp/)
    - [Visualization-of-Rule-from-Python-to-Cpp/](https://imjinshuo.github.io/RulER/visualization-of-mined-rules/Visualization-of-Rule-from-Python-to-Cpp/)
    - [Visualization-of-Rule-from-Cpp-to-Java/](https://imjinshuo.github.io/RulER/visualization-of-mined-rules/Visualization-of-Rule-from-Cpp-to-Java/)
    - [Visualization-of-Rule-from-Cpp-to-Python/](https://imjinshuo.github.io/RulER/visualization-of-mined-rules/Visualization-of-Rule-from-Cpp-to-Python/)

2. Click any `Rule-[Number].html` link to open it.

3. Each HTML file visualizes the AST structures defined by a translation rule with the following elements:

    - **Blue Nodes Tree**: Represents the source-language AST structure specified in the translation rule.

    - **Yellow Nodes Tree**: Represents the target-language AST structure specified in the translation rule.

    - **Node Annotations**: Each node is accompanied by text describing its AST type and a code example (the code example is for illustrative purposes only).

    - **Purple Arrows**: Indicate the translation mapping relationships between source and target AST trees.

    - **Red Arrows**: Indicate the translation mapping relationships between source and target AST subtrees.

4. Interact with the visualization:

    - Scroll the mouse wheel to zoom in/out of the AST visualization for better viewing.

    - Click on nodes to check their detailed information.

## Additional Notes

- The `visualization-script.py` file is the script used to generate these interactive HTML visualizations.
