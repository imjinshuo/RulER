## Steps to Review C++ to Java Translation Rules

1. Click any `Rule-[Number].html` link to open it.

2. Each HTML file visualizes the AST structures defined by a translation rule with the following elements:

    - **Blue Nodes Tree**: Represents the source-language AST structure specified in the translation rule.

    - **Yellow Nodes Tree**: Represents the target-language AST structure specified in the translation rule.

    - **Node Annotations**: Each node is accompanied by text describing its AST type and a code example (the code example is for illustrative purposes only).

    - **Purple Arrows**: Indicate the translation mapping relationships between source and target AST trees.

    - **Red Arrows**: Indicate the translation mapping relationships between source and target AST subtrees.

3. Interact with the visualization:

    - Scroll the mouse wheel to zoom in/out of the AST visualization for better viewing.

    - Click on nodes to check their detailed information.
