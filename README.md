# Artifact for the Paper "**RulER**: Automated Rule-Based Semantic Error Localization and Repair for Code Translation"

This is the artifact for the paper "****RulER**: Automated Rule-Based Semantic Error Localization and Repair for Code Translation**". This artifact supplies the replication package and the dataset of the paper.

## This artifact contains:
* [Introduction](#introduction)
* [Setup](#setup)
* [Dataset](#dataset)
* [Scripts](#scripts)
* [Usage Instruction](#usage-instruction)


## Introduction

**RulER** is an automated end-to-end debugging method for addressing semantic errors in code translation through rule-based localization and repair.

![Overview](figs/Overview.png)


## Setup
**To replicate the experiments, please follow these steps to prepare the necessary dependencies:**

- **Prepare a python environment:**
  - Execute the following commands:
    ```python
    conda create -n RulER python=3.10
    conda activate RulER
    pip install -r requirements.txt
    ```
  - Specifically, the following libraries in [**`requirements.txt`**](requirements.txt) will be installed:
    ```python
    nltk==3.8.1
    openai==1.84.0
    pexpect==4.9.0
    python_Levenshtein==0.27.1
    strsimpy==0.2.1
    tqdm==4.66.4
    tree_sitter==0.20.0
    ```
- **Download `Project_CodeNet.tar.gz` from https://developer.ibm.com/data/project-codenet/ and unzip it.**
- **Download `DATABASE.zip` from https://drive.google.com/file/d/1SSNidiFrTgq-7GyNxFkNiFg6Brp8eTE9/view?usp=sharing and unzip it into **`/data/DATABASE`**.**
- **Download `CodeNet_sourcefiles.zip` from https://drive.google.com/file/d/1EpJ4oUezUSOaVlCY8vkCjj6_iKyy3atu/view?usp=sharing and unzip it into **`/scripts/Module1-LLM-DrivenRuleBuilder/CodeNet_sourcefiles/`**.**
- **Download `CodeNet_filenames.zip` from https://drive.google.com/file/d/1vg0TIvXHAxXVNEMGRtRSygSVT0_-99MM/view?usp=sharing and unzip it into **`/scripts/Module1-LLM-DrivenRuleBuilder/CodeNet_filenames/`**.**

## Dataset

**The code translation rules generated by RulER and datasets needed for the experiment are stored in the [`/data/DATABASE`](data/DATABASE).**

**For convenient observation, we randomly sampled 4000 translation rules and presented their visualizations into interactive HTML files in [`/visualization-of-mined-rules`](/visualization-of-mined-rules). For more details, please refer to [`/visualization-of-mined-rules/README.md`](https://imjinshuo.github.io/RulER/visualization-of-mined-rules/).**

**Detailed information illustrating the structure and contents of our released dataset is provided in [`/data/Data.md`](/data/Data.md).**

Structure of [**`/data/DATABASE`**](DATABASE):
```
/data/DATABASE
┝━━ DATA/
│   ┝━━ BUG/ (labels for error localization)
│   ┝━━ CODE/ (code translations with semantic errors)
│   ┕━━ MAP/ (labels for code alignments)
┝━━ task-5000-qwen2.5-coder-32b-instruct-CodeNet-C++-Java/ (original mined C++-to-Java translation rules)
┝━━ task-5000-qwen2.5-coder-32b-instruct-CodeNet-C++-Java-Synthesis/ (synthesized C++-to-Java translation rules)
┝━━ task-5000-qwen2.5-coder-32b-instruct-CodeNet-C++-Python/ (original mined C++-to-Python translation rules)
┝━━ task-5000-qwen2.5-coder-32b-instruct-CodeNet-C++-Python-Synthesis/ (synthesized C++-to-Python translation rules)
┝━━ task-5000-qwen2.5-coder-32b-instruct-CodeNet-Java-C++/ (original mined Java-to-C++ translation rules)
┝━━ task-5000-qwen2.5-coder-32b-instruct-CodeNet-Java-C++-Synthesis/ (synthesized Java-to-C++ translation rules)
┝━━ task-5000-qwen2.5-coder-32b-instruct-CodeNet-Python-C++/ (original mined Python-to-C++ translation rules)
┕━━ task-5000-qwen2.5-coder-32b-instruct-CodeNet-Python-C++-Synthesis/ (synthesized Python-to-C++ translation rules)
```

# Usage Instruction

**We provide scripts to run RulER and reproduce all experimental results from RQ1 to RQ4.**

## Follow these steps to run RulER.

### 1. LLM-driven Rule Builder of RulER: 

+ ***Note:** Considering reproducing this module will cost lots of time, we have provided its execution results in [`DATABASE.zip`](https://drive.google.com/file/d/1SSNidiFrTgq-7GyNxFkNiFg6Brp8eTE9/view?usp=sharing) for replication.*

Run the following commands to extract code translation rules from translations generated by LLM qwen2.5-coder-32b-instruct (requires an api_key from https://www.aliyun.com/).

  ```bash
cd scripts/Module1-LLM-DrivenRuleBuilder

python step1-translate_codenet.py \
--source_lang Java-or-Python \
--target_lang C++ \
--tmp_dir tmp \
--CodeNet_data_path path/to/Project_CodeNet/data \
--model_name qwen2.5-coder-32b-instruct \
--CodeNet_test_input_path path/to/Project_CodeNet/derived/input_output/data \
--path_to_save_source_code CodeNet_sourcefiles \
--api_key api_key_of_qwen2.5-coder-32b-instruct

python step2-test_codenet.py \
--source_lang Java-or-Python \
--target_lang C++ \
--CodeNet_test_input_path path/to/Project_CodeNet/derived/input_output/data \
--tmp_dir tmp \
--model_name qwen2.5-coder-32b-instruct

python step3-delete_codenet.py \
--source_lang Java-or-Python \
--target_lang C++ \
--model_name qwen2.5-coder-32b-instruct \
--path_to_save_source_code CodeNet_sourcefiles

python step4-test_codenet.py \
--source_lang Java-or-Python \
--target_lang C++ \
--model_name qwen2.5-coder-32b-instruct \
--CodeNet_test_input_path path/to/Project_CodeNet/derived/input_output/data \
--tmp_dir tmp

python step5-translate_codenet.py \
--source_lang Java-or-Python \
--target_lang C++ \
--model_name qwen2.5-coder-32b-instruct \
--api_key api_key_of_qwen2.5-coder-32b-instruct

python step6-test_codenet.py \
--source_lang Java-or-Python \
--target_lang C++ \
--model_name qwen2.5-coder-32b-instruct \
--tmp_dir tmp

python step7-build_maps.py \
--source_lang Java-or-Python \
--target_lang C++ \
--model_name qwen2.5-coder-32b-instruct
  ```

### 2. Loop Execution of Code Aligner, Error Locator, and Patch Generator of RulER:

#### The first round:

**(1)** Execute the following command to run Code Aligner for the evaluation dataset.

  ```bash
cd scripts/Module2-CodeAligner

python run.py \
--source_lang Java-or-Python \
--target_lang C++ \
--target_model_name one_of_TransCoder_TransCoderST_Codex_Qwen2.5-Coder-32B-Instruct-data \
--model_name qwen2.5-coder-32b-instruct \
--path_to_code path/to/DATABASE/DATA/CODE \
--path_to_save_map_for_line path/to/save/maps/for/lines \
--path_to_save_map_for_statement path/to/save/maps/for/statements \
--path_to_save_unmapped_stmt path/to/save/unmapped/statements \
--path_to_DATABASE path/to/DATABASE
  ```
  

**(2)** Execute the following command to run Error Locator for the evaluation dataset.

  ```bash
cd scripts/Module3-ErrorLocator

python run.py \
--source_lang Java-or-Python \
--target_lang C++ \
--target_model_name one_of_TransCoder_TransCoderST_Codex_Qwen2.5-Coder-32B-Instruct-data \
--path_to_map path/to/maps/for/lines \
--path_to_unmapped_stmt path/to/unmapped/statements \
--path_to_save_FL path/to/save/fault/localization/results \
--path_to_label path/to/DATABASE/DATA/BUG \
--path_to_code path/to/DATABASE/DATA/CODE
  ```
  

**(3)** Execute the following command to run Patch Generator for the evaluation dataset.

  ```bash
cd scripts/Module4-PatchGenerator

python run.py \
--source_lang Java-or-Python \
--target_lang C++ \
--target_model_name one_of_TransCoder_TransCoderST_Codex_Qwen2.5-Coder-32B-Instruct-data \
--model_name qwen2.5-coder-32b-instruct \
--path_to_map path/to/maps/for/lines \
--path_to_stmtmap path/to/maps/for/statements \
--path_to_code path/to/DATABASE/DATA/CODE \
--path_to_fixcode path/to/save/repaired/translations \
--path_to_DATABASE path/to/DATABASE \
--path_to_unmapped_stmt path/to/unmapped/statements
  ```

**(4)** Execute commands below to verify the patches generated by Patch Generator. The verification results will be stored in files within the **`/Info`** folder.

  ```bash
cd scripts/Test

python step1-fill_script.py \
--path_to_fixcode path/to/repaired/translations \
--path_to_DATABASE path/to/DATABASE

python step2-rewrite_script.py

python step3-rewrite_script_uncompare.py

python step4-test_script.py \
--source_lang Java-or-Python \
--target_lang C++ \
--target_model_name one_of_TransCoder_TransCoderST_Codex_Qwen2.5-Coder-32B-Instruct-data \
--tmp_dir tmp \
--start_id 0 \
--end_id 1000

python step5-read_test_results.py \
--path_to_DATABASE path/to/DATABASE

python step6-compare-trace.py \
--source_lang Java-or-Python \
--target_lang C++ \
--target_model_name one_of_TransCoder_TransCoderST_Codex_Qwen2.5-Coder-32B-Instruct-data \
--path_to_map path/to/maps/for/lines \
--path_to_code path/to/DATABASE/DATA/CODE \
--path_to_DATABASE path/to/DATABASE \
--tmp_dir tmp

# The last command will generate "/Code-round2", "/new_passinfo", and "/t_passinfo", which will be needed for executing the 2nd round of RulER.
  ```
